# 팀 프로젝트 성향 테스트 (미니 에고그램)

👉 테스트 바로가기

"우리 팀의 환상의 짝꿍은 누구일까?" > PBL 및 팀 프로젝트 시작 전, 서로의 성향을 파악하고 대화의 물꼬를 트기 위해 제작된 웹 애플리케이션입니다.

심리학의 에고그램(Egogram) 이론을 기반으로, 복잡한 심리학 용어 대신 팀 내 캐릭터(예: 칼각 원칙주의자, 다정다감 케어러 등)로 결과를 직관적으로 풀어냈습니다. 단일 HTML 파일로 구성되어 있어 복잡한 환경 설정 없이 누구나 쉽게 코드를 확인하고 수정할 수 있습니다.

주요 기능

30개의 상황별 문답: 직장이나 조별 과제에서 흔히 겪는 현실적인 상황 기반 질문 제공

5가지 캐릭터 결과 도출: 점수에 따라 메인 캐릭터(1순위)와 '내 안의 부캐'(2순위) 도출

소통 꿀팁 및 역할 추천: 캐릭터별 업무 협업 팁(나랑 일할 땐 이렇게 해줘요) 및 PBL 추천 역할 제공

팀원 궁합 시스템: 시너지 폭발 짝꿍(최고의 궁합)과 이해가 필요한 짝꿍(주의 궁합) 안내

밸런스 붕괴 주의보 (이스터에그): 특정 성향이 극단적으로 높은 사용자에게만 나타나는 숨겨진 피드백

결과 이미지 캡쳐: 모바일과 PC 환경 모두에서 깨짐 없이 결과를 이미지로 저장 (html2canvas 활용)

답변 돌아보기: 테스트 완료 후 자신이 선택한 30개의 답변을 팝업 형태로 다시 확인 가능

5가지 팀 프로젝트 캐릭터

에고그램의 5가지 자아 상태(CP, NP, A, FC, AC)를 팀워크에 맞춰 재해석했습니다.

팀의 든든한 가드레일, 칼각 원칙주의자 (CP) : 규칙과 마감을 중시하는 리더형

팀의 힐링 포션, 다정다감 케어러 (NP) : 공감과 배려로 분위기를 부드럽게 만드는 조율자

팀의 네비게이션, 냉철한 팩트폭격기 (A) : 이성적이고 논리적인 판단을 내리는 브레인

팀의 스파크, 자유로운 아이디어 뱅크 (FC) : 틀에 얽매이지 않고 창의적인 아이디어를 던지는 메이커

팀의 윤활유, 평화주의자 조율러 (AC) : 타인을 배려하며 묵묵히 팀을 서포트하는 조력자

기술 스택

UI & Logic: React 18, Babel (Standalone)

Styling: Tailwind CSS (CDN)

Icons: Custom Inline SVGs (Lucide-based)

Libraries: html2canvas (결과 이미지 다운로드), canvas-confetti (폭죽 애니메이션)

Architecture: Zero-build Single HTML File (index.html 단일 파일로 동작)

실행 방법

배포된 링크를 통해 바로 이용하시거나, 코드를 다운받아 로컬 환경에서 실행할 수 있습니다.

1. 웹에서 바로 실행하기

https://yang-yun-seok.github.io/egogram/

2. 로컬 환경에서 실행하기

해당 저장소의 코드를 다운로드 받습니다.

index.html 파일을 더블 클릭하여 웹 브라우저(Chrome, Safari 등)에서 엽니다.

별도의 npm install 이나 빌드 과정 없이 즉시 실행됩니다.
